Free for teachers · Google Apps Script

Classroom apps for English teachers

Units and tools built and used in a real high-school English classroom. Make your own copy and use it tomorrow, or change the code however you like.

Browse the apps All the code on GitHub

How it works

Each app runs in your own Google account. Your students’ work saves to your Drive. Nothing is shared with anyone else.

  1. Make a copy

    One click copies the app into your Google account.

  2. Run setup once

    It builds the app’s Sheet and makes you the admin. Add other teachers at your school from inside the app.

  3. Share your link

    Deploy it as a web app and post the link for students. Connect Canvas if you like.

The apps

You’ll need a Google Workspace for Education account, so students sign in with their school Google account. Canvas and AI feedback are optional.

MC

Macbeth Curriculum

Grades 9–12

A full Macbeth unit: the play act by act with side-by-side support, activities, discussion, grading and Canvas.

Copy link soon View code
Set it up
  1. Follow the setup guide to add the files to a new Apps Script project.
  2. In your copy, open Extensions → Apps Script.
  3. Pick setupMacbethBackend in the function list, click Run, and allow the permissions. You’re now the admin.
  4. Deploy → New deployment → Web app: execute as Me, access for anyone in your school. Share that link with students.

Full setup guide · Canvas and AI feedback are optional.
